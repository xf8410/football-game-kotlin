## 五、随本轮一并修复的自测 Bug（用户报告）
- 裁判跑位不对 → 对角线跑位（球斜后 9m + 固定通道，距球 ≥6m）✅
- 球员跑位过于密集 → 7m 加权分离力 ✅
- 球出界球员还在盘带 → 持球出界立即鸣哨收球权 ✅
- 球出界不吹、不给对手球权 → 界外球/球门球/角球系统 ✅
- 草坪/整体画面太暗 → 草皮条纹提亮约 +85%、环境光 0.62→0.80、看台提亮 ✅
- 按钮切换时抽搐抖动 → 大按钮三态迟滞（射门 24→29m、铲球 2.8→3.6m 退出阈值）+ 按键固定槽位布局 ✅
- 射门按键有时不显示 → 射门显示区放宽 + 迟滞保持 ✅
- 横屏 → Manifest 已锁横屏（本包验证）✅
