# ⚽ 足球游戏 Kotlin 版 (Football Game Kotlin)

[![Build](https://github.com/xf8410/football-game-kotlin/actions/workflows/build.yml/badge.svg)](https://github.com/xf8410/football-game-kotlin/actions/workflows/build.yml)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

基于 Godot GDScript 版本重写的 Android 原生足球游戏。

## 📱 功能特性

### ⚽ 进球方式系统
| 类型 | 方式 | 描述 |
|------|------|------|
| **射门** | 普通射门 | 常规射门得分 |
| | 大力抽射 | 力量十足的射门 |
| | 巧射 | 角度刁钻的射门 |
| | 远射 | 禁区外远射得分 |
| | 一脚射门 | 不停球直接射门 |
| **特殊射门** | 搓射 | 弧线球射门 |
| | 电梯球 | 不旋转的飘忽射门 |
| | 吊射 | 挑过门将的射门 |
| | 外脚背 | 外脚背射门 |
| | 倒钩射门 | 腾空倒钩 |
| | 凌空抽射 | 球落地前射门 |
| | 倒挂金钩 | 身体后仰腾空射门 |
| | 脚后跟射门 | 脚后跟磕球射门 |
| **头球** | 头球 | 常规头球攻门 |
| | 头球冲顶 | 力量十足的头球 |
| | 鱼跃头球 | 腾空头球攻门 |
| | 头球蹭射 | 改变球方向的头球 |
| **配合** | 传中射门 | 接传中球射门得分 |
| | 传中头球 | 接传中球头球攻门 |
| | 倒三角射门 | 接倒三角传球射门 |
| | 做球射门 | 接队友做球射门 |
| | 二过一射门 | 撞墙配合后射门 |
| **补射** | 补射 | 门将扑出后补射得分 |
| | 混战进球 | 禁区内混战中进球 |
| **定位球** | 直接任意球 | 任意球直接破门 |
| | 角球头球 | 角球传中头球攻门 |
| | 角球直接射门 | 角球直接旋进球门 |
| | 点球 | 点球罚进 |
| | 勺子点球 | 勺子点球罚进 |
| **其他** | 个人突破进球 | 带球突破多人后射门 |
| | 快速反击进球 | 反击中快速进攻得分 |

### 🏆 进球术语播报（左上角显示）
| 进球数 | 术语 | 描述 |
|--------|------|------|
| 1球 | 首开纪录 | 打进本场比赛第一球 |
| 2球 | **梅开二度** | 同一球员打进两球 |
| 3球 | **帽子戏法** | 同一球员打进三球 |
| 4球 | **大四喜** | 同一球员打进四球 |
| 5球 | **五子登科** | 同一球员打进五球 |
| 6球 | **独中六元** | 同一球员打进六球 |

### 🎯 进球位置术语
- 禁区外 - 远射破门
- 禁区内 - 禁区内破门
- 六码区 - 近距离破门
- 远门柱 - 后点破门
- 近门柱 - 前点破门
- 球门死角 - 世界波
- 球门下角 - 死角破门

### ⏱️ 进球时间术语
- 1-15分钟 - 闪击破门
- 31-45分钟 - 半场前破门
- 46-60分钟 - 下半场开局破门
- 76-90分钟 - 终场前破门
- 90+分钟 - **绝杀！**
- 加时赛 - 加时赛进球

### 🎯 比赛场景术语
- 扳平比分 - 将比分扳平！
- 取得领先 - 取得领先！
- 扩大领先 - 扩大领先优势！
- **绝杀！** - 比赛制胜球！
- 终场前扳平 - 终场前扳平比分！

### ✅ 物理和碰撞系统
- **真实碰撞体积** - 圆柱体碰撞，防止穿模
- **身体对抗** - 抢断时的物理对抗
- **护球机制** - 保护球不被抢断
- **爆趟突破** - 快速带球突破

### ✅ 五大联赛 + 传奇球星
- 37支五大联赛球队
- 50+当前球星
- 35+传奇球星（不同时代）

## 📁 项目结构
```
app/src/main/java/com/football/game/
├── core/               # 核心游戏逻辑
│   ├── GameEngine.kt   # 游戏引擎
│   ├── GameState.kt    # 游戏状态
│   ├── PlayerModel.kt  # 球员模型和碰撞
│   ├── PhysicsSystem.kt# 物理系统
│   ├── DribbleSystem.kt# 盘带系统
│   └── GoalTypes.kt    # 进球方式系统
├── ui/component/       # UI组件
│   └── GoalAnnouncementUI.kt  # 进球播报UI
├── data/               # 数据管理
├── ai/                 # AI系统
└── render/             # 渲染系统
```
